# SecondEgo website

The website is a Vite + React + TypeScript application. The app entrypoint is
`src/main.tsx`, the root component is `src/App.tsx`, and reusable page sections
live under `components/`.

Run locally with `npm run dev` and build with `npm run build`. Keep the site
static, accessible, responsive, and honest about which repository behaviors are
verified versus illustrative.
