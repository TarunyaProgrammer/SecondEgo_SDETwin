# Support

This is an experimental project. Before asking for help:

1. Read [`README.md`](README.md), [`AGENTS.md`](AGENTS.md), and [`CONTEXT.md`](CONTEXT.md).
2. Search existing issues and documentation.
3. Provide the commit or version, environment, exact command, relevant logs, and a minimal reproduction.

Do not post secrets, access tokens, private repository contents, or undisclosed security vulnerabilities. Use [`SECURITY.md`](SECURITY.md) for security reports.
